# 🌾 Khet AI - Naming Schema & Project Setup Guide

## 🧩 Naming Schema (for Better Organization)

| Feature              | Code | Description                |
|----------------------|------|-----------------------------|
| 🌱 Crop Recommendation | **CR** | Suggests the best crop based on soil & conditions |
| 🌾 Crop Yield          | **CY** | Predicts expected yield for a crop |
| 💧 Crop Fertilizer     | **CF** | Recommends fertilizers for crops |
| 💰 Crop Price          | **CP** | Predicts or displays market price |
| 🍃 Crop Disease        | **CD** | Detects plant diseases from images |

## 🚀 How to Start the Project

### 🖥️ Frontend Setup

```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Run the development server
npm run dev
```

### ⚙️ Backend Setup


```bash
# Navigate to backend directory
cd backend

# Install Python dependencies
pip install -r requirements.txt

# Activate virtual environment
venv\Scripts\activate  # (Use source venv/bin/activate on macOS/Linux)

# Start the Flask server
python app.py

```

### ✅ Notes

<ul>
 <li> Make sure Node.js and Python 3.10+ are installed. </li>
 <li>Ensure both frontend and backend are running simultaneously for full functionality.</li>
 <li>Backend runs on Flask; frontend on React + Vite + Tailwind.</li>
</ul>
